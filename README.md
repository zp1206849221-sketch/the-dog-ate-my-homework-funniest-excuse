# The Dog Ate My Homework: Funniest Excuse

A one-line excuse in the dog's own voice, delivered with total confidence and impeccable dog law: if it is on the floor, it is legally the dog's property.

## Run

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if needed).
